テキスト専用 Gemma4 への回帰とアイコンぼやけ対策

dev 2026-06-30 22:33 JST commit: pending

概要

小型 Gemma4 では画像テキスト抽出が実用にならず、マスターの指示で 画像添付（「+」）・OCR・マルチモーダル（mmproj）を全撤去し、 テキストチャット専用構成に戻した。あわせて再発していた EXE アイコンのぼやけを調査し、原因が ICO ではなく Windows アイコンキャッシュであることを特定して対処した。

変更ファイル

  • MNotepad/chat_gui.py — 「+」ボタン・添付バー・OCR 解析・画像プロンプト合成・debug ログを除去。送信は純テキストのみ
  • MNotepad/llm_utils.py — Gemma4ChatHandler・mmproj 探索・data URL・マルチモーダル分岐・textify を除去。respond() はテキスト生成に一本化
  • -Notepad/image_utils.py — ファイルごと削除
  • MNotepad/ensure_icon.py — 各 ICO フレームを 512px 原画から個別 LANCZOS 縮小（append_images）。debug ログ除去
  • MNotepad/build.ps1 — mmproj コピー処理を削除
  • Mrequirements.txt — pytesseract / rapidocr-onnxruntime を削除（Pillow は残置）
  • -models/mmproj-BF16.gguf 他（dist・HF キャッシュ含む）— 約 941MB×2 解放

設計判断

E2B クラスの小型モデルでは画像 OCR の出力が安定せず（「化して」等の崩壊応答）、 OCR エンジン（RapidOCR/Tesseract/WindowsOCR）も日本語精度・環境依存で実用性が低かった。 機能を残すよりテキストチャットに集中する方が UX・配布サイズ・保守性すべてで有利と判断し撤去。

入力（テキスト） → Gemma4 (gguf) → ストリーミング応答
